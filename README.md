## Category-Partition ба Microsoft PICT

- Хичээл: F.CSA313 — Программ хангамжийн чанарын баталгаа ба тест
- Оюутны нэр: Munkhjin

# Хэсэг A — Category-Partition

## A1. Сонголт ба төлөөлөх утгууд

Шалгах функц: `POST /transfer`

Оролтын бүтэц:
`{"from": ID, "to": ID, "amount": NUM, "currency": CODE}`

### Параметрийн сонголтууд

| Параметр | Сонголт (Category) | Төлөөлөх утга (Choice) | Тайлбар |
|---|---|---|---|
| from | Дансны оршин байгаа эсэх | Valid | Данс бүртгэлтэй, царцаагдаагүй |
| from | Дансны төлөв | Frozen | Данс бүртгэлтэй боловч царцаагдсан |
| from | Дансны оршин байгаа эсэх | Missing | Данс олдохгүй |
| to | Хүлээн авагчийн данс | Valid | Бүртгэлтэй, шилжүүлэгчээс өөр данс |
| to | Хүлээн авагчийн данс | Missing | Хүлээн авагчийн данс олдохгүй |
| to | Дансны хамаарал | SameAsFrom | Шилжүүлэгч ба хүлээн авагч ижил |
| amount | Шилжүүлгийн хэмжээ | Normal | Тэгээс их, үлдэгдэл ба лимитэд багтана |
| amount | Шилжүүлгийн хэмжээ | Zero | Хэмжээ тэгтэй тэнцүү |
| amount | Шилжүүлгийн хэмжээ | Negative | Хэмжээ тэгээс бага |
| amount | Үлдэгдэл | OverBalance | Хөрвүүлсний дараах дүн үлдэгдлээс их |
| amount | Өдрийн лимит | OverLimit | Хөрвүүлсний дараах дүн лимитээс их |
| currency | Валютын хамаарал | Same | Дансны валюттай ижил |
| currency | Валютын хамаарал | Different | Дансны валютаас өөр, хөрвүүлэлт шаардлагатай |

### Далд орчны сонголтууд

| Орчны сонголт | Төлөөлөх утгууд | Нөлөө |
|---|---|---|
| Шилжүүлэгчийн үлдэгдэл | Хангалттай / Хангалтгүй | Шилжүүлэг зөвшөөрөгдөх эсэхэд нөлөөлнө |
| Өдрийн лимитийн үлдэгдэл | Хангалттай / Хүрэлцэхгүй | Лимит хэтэрсэн эсэхийг тодорхойлно |
| Валют хөрвүүлэлт | Хөрвүүлэлт шаардлагагүй / Шаардлагатай | Үлдэгдэл ба лимитийг шалгах дүнд нөлөөлнө |

Тайлбар: `Normal` нь тухайн дансны үлдэгдэл болон өдрийн лимитэд багтах хүчинтэй дүнг илэрхийлнэ. `OverBalance`, `OverLimit` нь валют хөрвүүлсний дараах дүнгээр тодорхойлогдоно. Тодорхойлолтод валютын код буруу байх үеийн алдааны төрөл заагаагүй тул энэ лабораторид тусгай oracle зохиож нэмээгүй.
